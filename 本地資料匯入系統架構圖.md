## 🧩 模組關係圖

```
src/importer/
│
├── __init__.py
│   └── 匯出所有處理器和匯入器
│
├── base_processor.py (基礎類別)
│   ├── can_process()      → 檢查是否支援
│   ├── process()          → 處理檔案(抽象方法)
│   ├── validate_data()    → 驗證資料
│   ├── standardize_data() → 標準化
│   ├── extract_keywords() → 提取關鍵詞
│   └── detect_period()    → 偵測時期
│
├── pdf_processor.py (繼承 BaseProcessor)
│   ├── _extract_text_pdfplumber()
│   ├── _extract_text_pypdf2()
│   ├── _parse_pdf_content()
│   ├── _is_structured_format()
│   ├── _parse_structured_format()
│   └── _parse_paragraph_format()
│
├── json_processor.py (繼承 BaseProcessor)
│   ├── _process_json()
│   ├── _process_jsonl()
│   └── create_template()
│
├── text_processor.py (繼承 BaseProcessor)
│   ├── _is_markdown_format()
│   ├── _is_structured_format()
│   ├── _process_markdown()
│   ├── _process_structured()
│   ├── _process_separated()
│   ├── _process_freetext()
│   └── create_template()
│
└── importer.py (協調器)
    ├── import_file()         → 匯入單一檔案
    ├── import_directory()    → 匯入整個目錄
    ├── _select_processor()   → 選擇處理器
    ├── _save_to_databases()  → 儲存到資料庫
    ├── _connect_neo4j()      → 連接Neo4j
    ├── _connect_chromadb()   → 連接ChromaDB
    ├── _save_to_neo4j()      → 儲存到Neo4j
    ├── _save_to_chromadb()   → 儲存到ChromaDB
    └── print_stats()         → 顯示統計
```

## 📊 系統擴展性架構

```
當前支援的格式
├─ PDF
├─ JSON
└─ TXT/MD

未來可擴展
├─ CSV
│  └─ 建立 CSVProcessor(BaseProcessor)
├─ Excel
│  └─ 建立 ExcelProcessor(BaseProcessor)
├─ XML
│  └─ 建立 XMLProcessor(BaseProcessor)
└─ 圖片(OCR)
   └─ 建立 ImageProcessor(BaseProcessor)

擴展步驟:
1. 繼承 BaseProcessor
2. 實作 can_process()
3. 實作 process()
4. 註冊到 importer.processors
```
